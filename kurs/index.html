Система

Несколько агентов работают вместе: проверки, заметки о прогрессе, работа по расписанию — «второй мозг» и пульт.

Практика

Порядок для новичка: ступень 1 → начало 3 → 2 → конец 3 → 4. Практиковать контекст удобнее, когда уже есть работающий агент. Бесплатная теория по каждой ступени — в маршруте по ИИ.
